## What changed

The first version.

* Greedy best-first search. At each step the model gets one question, with every
  frontier state as an option, and the search explores the state it picks. The
  classic arm makes the same search with the domain's heuristic.
* A breadth-first search finds the shortest path of each trial. The score of a
  trial is the explorations of a perfect search (the shortest path + 1) divided by
  the explorations of the model arm, so 1.0 is perfect. The classic arm and an
  oracle arm, which knows the true distance to the goal, get the same score. The
  path score is the shortest path divided by the path the model arm found. A
  domain's score is the geometric mean over its trials.
* The frontier holds at most 255 states, the most options a Jev question holds.
  Above that, states leave at random, by the same rule for both arms.
* The domains have a heuristic that is reasonable and not near perfect, a frontier
  that fits in one question, and trials that finish in reasonable time.

### Optimal choices as text

A state is optimal when it is on a shortest path: its moves from the start plus its moves to the goal equal the length of a shortest path. A decision counts when the frontier has an optimal state and a state that is not optimal. The percent is the mean over trials of the percent of the counted decisions that took an optimal state, so each trial counts the same.
